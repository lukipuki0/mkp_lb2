% Diagnostic figures for the best DTW/DDTW configuration of each MKP instance.
% This is an input fragment for paper/results.tex.  The figures use only
% graphicx, which is already loaded by the main paper preamble.
%
% Selection criterion: lowest mean optimality gap among DTW--1K, DDTW--1K,
% DTW--3K, and DDTW--3K.  The paired plots correspond to the best run stored
% for the selected campaign.

Figures~\ref{fig:mkp-best-cb1}--\ref{fig:mkp-best-cb9} show the convergence
trajectory and the $\Delta$ monitor for the best-performing framework
configuration selected independently for each MKP instance. The selection is
based on the lowest mean optimality gap over 31 runs: DTW--3K is selected for
\texttt{mknapcb1} and \texttt{mknapcb3}--\texttt{mknapcb8}, whereas DDTW--3K
is selected for \texttt{mknapcb2} and \texttt{mknapcb9}. Each pair uses the
best run reported by the corresponding campaign.
