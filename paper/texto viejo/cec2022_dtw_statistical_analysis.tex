\section{Statistical Analysis of the CEC 2022 DTW Benchmark}
\label{sec:cec2022-dtw-statistics}

This section provides the complete statistical interpretation of the new DTW
benchmark. The analysis is based on 31 independent runs of seven algorithms on
each of the 12 CEC 2022 functions. Because the functions have different
scales and optima, all global conclusions are obtained from per-function
ranks and paired per-function comparisons; raw objective values are used only
for descriptive summaries. DTW and DDTW are analyzed as two variants of the
hybrid pipeline under the same experimental protocol.

\subsection{Analysis protocol}

For each function, the seven algorithms were run with the same number of
iterations and independent-run budget. Each hybrid is the reference method in
its own pairwise tests. The null hypotheses are:

\begin{itemize}
  \item $H_0^{\mathrm{F}}$: all seven algorithms have the same distribution of
  performance ranks on a given function;
  \item $H_0^{\mathrm{W}}$: a given hybrid and comparator have the same
  paired performance distribution;
  \item $H_0^{\mathrm{MW}}$: a given hybrid and comparator have the same
  marginal performance distribution.
\end{itemize}

The Friedman test is applied independently to the seven algorithm columns for
each function. When it is significant, the two-sided Wilcoxon signed-rank test
is used for the paired comparison between each hybrid and each standalone
method. A two-sided Mann--Whitney $U$ test is also recorded as a complementary
distributional check. The significance level is $\alpha=0.05$. The generated
CSV and Markdown reports contain both raw and Holm-adjusted Wilcoxon p-values.
Significance labels are based on the Holm-adjusted values within each function
(the five hybrid-versus-baseline comparisons). The per-function Friedman tests
are the primary omnibus evidence.

The Wilcoxon conclusion is expressed from the perspective of the hybrid under
analysis:
``better'' means that the hybrid has the lower objective values, ``worse''
means that the comparator has the lower values, and ``similar'' means that the
test did not reject equality at $\alpha=0.05$. Since this is a minimization
benchmark, lower values always imply better performance.

\subsection{Normality and robustness considerations}

The Shapiro--Wilk diagnostic for both hybrids rejects normality at the 5\%
level on 10 of the 12 functions. For DTW, F4 and F12 are the only functions
with p-values above 0.05 (approximately 0.181 and 0.124); for DDTW, the
corresponding p-values are approximately 0.811 and 0.238. This supports the use of
rank-based tests rather than relying on a normal-theory comparison of means.
It also reinforces the need to report medians and dispersion in addition to
means.

The statistical evidence is strongest for the cross-function rank conclusion:
both hybrids have the lowest average ranks and are significantly better in more
pairwise comparisons than any baseline. Nevertheless, F6 shows substantial
variance and standalone methods outperform the hybrids in selected landscapes.
The appropriate conclusion is therefore that DTW and DDTW provide competitive
and robust overall performance, with a small descriptive rank advantage for
DTW, not that either variant provides universal dominance.

\subsection{Limitations and reproducibility}

The generated benchmark reports apply Holm correction separately within each
function to the five baseline comparisons for each hybrid. The appendix tables
below retain the raw Wilcoxon p-values from the archived campaign; therefore,
their numerical decisions should be regenerated from the corresponding
per-function CSV files when multiplicity-adjusted decisions are required. The
benchmark output stores both Wilcoxon and
Mann--Whitney p-values, but it does not store a standardized effect size or a
confidence interval; these should be added in a future rerun if effect-size
reporting is required.

It is not valid to combine the raw objective values of F1--F12 into a single
Friedman test because the functions have different scales and shifted
optima. The per-function Friedman tests, per-function ranks, and the
cross-function average of normalized ranks used here avoid that scale
problem. All numerical inputs can be reproduced from
\texttt{continuous\_benchmark/resultados/run\_dtw\_job\_19070/} and
\texttt{continuous\_benchmark/resultados/run\_ddtw\_job\_19066/}, in
particular from each \texttt{resumen\_global.csv}, each
\texttt{runs\_resultados.csv}, and each
\texttt{analisis\_estadistico\_pvalues.csv}.
